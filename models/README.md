# models

ここにモデルを置きます（同梱していません）。別の場所に置いたモデルを使うときは、起動後の設定の「モデル」でフォルダを指定します。

- チャット用: `.gguf` のファイルを、この `models` の直下か `models\chat\` に置きます。
- 画像用: `models\image\<モデル名>\` に、本体・テキストエンコーダ・VAE をまとめて置きます（下を参照）。

置いたモデルは、ウィンドウに戻ると一覧に出ます。ダウンロードの途中のファイルは出しません。

## 画像用のモデル

画像の生成・編集には、stable-diffusion.cpp を `bin\sd\` に入れておく必要があります（[bin/README.md](../bin/README.md)）。

`models\image\` の中に、モデル 1 つにつき 1 つのフォルダを作り、次の 3 種類のファイルをまとめて入れます。種類はファイル名ではなく中身で見分けるので、名前を変えてもかまいません。

```
models\
└─ image\
    ├─ <モデル名 1>\    ← 本体・テキストエンコーダ・VAE
    └─ <モデル名 2>\
```

SimpLLM はモデルを同梱せず、入手先も案内しません。どのモデルを使うか、入手とライセンスの確認は、利用者に任せます。

同梱の設定があるのは、次の系統です。

| 系統 | 本体 | テキストエンコーダ | VAE | 指示の言語 |
|---|---|---|---|---|
| Chroma / Chroma Flash | Chroma の本体（GGUF） | T5-XXL | FLUX.1 系の VAE | 英語（日本語の指示は、チャットのモデルで英訳してから使う。設定でオフにできる） |
| Qwen-Image 2.1 | Qwen-Image 2.1 の本体（GGUF） | Qwen3-VL 8B | Qwen-Image 2.1 の VAE | 日本語のまま使える |

- Chroma は、本体のファイル名に「Flash」を含むと Flash 用の設定を使います。
- Qwen-Image 2.1 の同梱の設定は、確認の途中です。
- そのほかの系統も、標準的な値の設定を自動で作って試せます（未確認の設定として表示します）。設定の「モデル」から直せます。
- 足りないファイルがあるときは、設定の「モデル」の一覧に理由を表示します。

開発用の PC（RTX 3060、VRAM 12GB）では、1024×1024 の 1 枚に Chroma Flash で約 43 秒、Qwen-Image 2.1 で約 105 秒かかりました。画像を作る間は、チャットのモデルをいったん解放して VRAM を空けます。
